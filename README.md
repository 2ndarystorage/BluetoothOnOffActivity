## Program Summary
- Android app with two buttons that open Bluetooth settings screens: `BLUETOOTH_SETTINGS` and `BLUETOOTH_DASHBOARD_SETTINGS`.
- Requests `BLUETOOTH_CONNECT` permission before opening the dashboard settings screen.

## How to Use
- Not verified: Open the project in Android Studio, build, and run on a device/emulator (min SDK 31), then tap the buttons to open the system Bluetooth settings screens.

## Completion Status
- Prototype: Single-activity UI with two buttons and basic permission handling; no additional features or tests beyond boilerplate.
